1. What is Artificial Intelligence (AI)?

  • Simple Definition: Artificial Intelligence is the broad engineering discipline of creating computer systems that can perform tasks normally requiring human intelligence — such as recognizing images, understanding spoken words, making decisions, or translating languages.
  • Real-World Example: An automated chess game, a power-grid load controller that reroutes electricity during a storm, or a smartphone camera that detects human faces.
  • Technical Explanation: AI encompasses rule-based expert systems (if-then logic), search algorithms (A*, minimax), optimization, and learning algorithms. It is the umbrella term for any machine that mimics human cognitive functions.
  • How it Relates to This Project: Our project is an AI system because it reads unstructured human natural language (a movie review) and makes an intelligent cognitive judgment: "Is this person satisfied or dissatisfied?"

2. What is Machine Learning (ML)?

  • Simple Definition: Machine Learning is a specific branch of AI where, instead of explicitly writing thousands of rules by hand, we give the computer historical examples and let it learn the statistical patterns on its own.
  • Real-World Example: Instead of writing 10,000 rules to identify spam emails ("if contains 'lottery' then spam", "if contains 'wire money' then spam"), you feed the computer 50,000 emails labeled as "Spam" or "Not Spam" and let it discover which word combinations indicate spam.
  • Technical Explanation: Arthur Samuel (1959) defined ML as "the field of study that gives computers the ability to learn without being explicitly programmed." Mathematically, ML finds a mapping function $f: X ightarrow Y$ by minimizing an objective loss function over training data.
  • How it Relates to This Project: We do not write rules like if "good" in review: return positive. We feed our machine learning model 39,665 labeled reviews, and it learns numerical weights for 10,000 terms automatically.

4. What is Supervised Learning?

  • Simple Definition: A type of machine learning where the computer learns from data that already contains the "correct answers" (called labels). It is like studying for an exam with textbook problems accompanied by the answer key at the back.
  • Real-World Example: Teaching a child to identify fruits by showing pictures with labels: "This is an apple", "This is an orange".
  • Technical Explanation: Given a dataset $\mathcal{D} = \{(x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)\}$ where $x_i \in \mathbb{R}^d$ are feature vectors and $y_i$ are ground-truth targets, the algorithm optimizes parameters $\mathbf{w}$ to minimize prediction error $\mathcal{L}(f(x_i; \mathbf{w}), y_i)$.
  • How it Relates to This Project: Our project is 100% Supervised Learning. Every review in our training set came paired with its ground-truth sentiment label (positive = 1, negative = 0).

5. What is Unsupervised Learning?

  • Simple Definition: Machine learning where the data has no answer key or labels. The algorithm's job is to discover hidden patterns, clusters, or groupings on its own.
  • Real-World Example: Grouping supermarket customers into 4 distinct buying personas based on their purchase history, without knowing their categories in advance (Customer Segmentation).
  • Technical Explanation: Algorithms like K-Means Clustering, Principal Component Analysis (PCA), and Autoencoders discover intrinsic geometric or statistical structures within $X$ without target $Y$.
  • How it Relates to This Project: We did not use unsupervised learning for our core task because we already possessed 50,000 ground-truth human-annotated sentiment labels.

6. What is Classification?

  • Simple Definition: A supervised learning task where the target output is a category or discrete label (e.g., Yes/No, Cat/Dog, High/Medium/Low).
  • Real-World Example: A power transformer oil quality diagnostic system that classifies condition as "Healthy", "Warning", or "Faulty".
  • Technical Explanation: In binary classification, the output $y \in \{0, 1\}$. In multi-class, $y \in \{1, 2, \dots, K\}$. The algorithm computes decision boundaries separating discrete classes in feature space.
  • How it Relates to This Project: Our project is a Binary Classification task: predicting whether $y = 1$ (Positive) or $y = 0$ (Negative).

7. What is Regression?

  • Simple Definition: A supervised learning task where the target output is a continuous numerical quantity (e.g., price, temperature, power demand).
  • Real-World Example: Predicting tomorrow's peak electrical demand in Megawatts (MW) based on weather temperature and industrial activity.
  • Technical Explanation: In regression, the output $y \in \mathbb{R}$. The model fits a continuous function to minimize Mean Squared Error (MSE).
  • Note: Even though our algorithm is named Logistic Regression, it is strictly used for Classification because its continuous output is passed through a Sigmoid function to output class probabilities!

8. What is a Feature?

  • Simple Definition: An individual measurable property or characteristic used by the machine learning model to make its decision.
  • Real-World Example: When predicting house prices, features are: square footage, number of bedrooms, location, and year built.
  • Technical Explanation: An input variable $x_j$ representing an axis in a $d$-dimensional feature space. A collection of $d$ features forms a feature vector $\mathbf{x} = [x_1, x_2, \dots, x_d]^T$.
  • How it Relates to This Project: In our project, raw words cannot be fed directly to the model. Each unique vocabulary word or bigram (e.g., "masterpiece", "not good", "boring") becomes a distinct feature column whose numerical value is its TF-IDF score. Our model uses exactly 10,000 features.

9. What is a Target (or Label)?

  • Simple Definition: The actual outcome or answer that the model is trying to predict.
  • Real-World Example: The actual selling price of the house, or whether an electrical transformer tripped (1) or did not trip (0).
  • Technical Explanation: The dependent variable $y$. In our dataset, the raw column sentiment has text strings "positive" and "negative".

  • Simple Definition: The portion of your historical dataset (usually 70%–80%) given to the model during the learning phase so it can discover patterns.
  • Real-World Example: The practice problems and textbook exercises a student studies throughout the semester.
  • How it Relates to This Project: We allocated 80% of our 49,582 clean reviews — exactly 39,665 reviews — as our Training Set.

11. What is Testing Data (Holdout Set)?

  • Simple Definition: The remaining portion of the dataset (usually 20%–30%) hidden from the model during training, used exclusively to test how well the model performs on completely unseen data.
  • Real-World Example: The final unseen exam questions given to the student at the end of the year to test genuine comprehension rather than rote memorization.
  • How it Relates to This Project: We set aside 20% — exactly 9,917 reviews — as our Test Set. The model was evaluated on these 9,917 reviews to calculate our final 90.23% accuracy.

12. What is a Model?

  • Simple Definition: The mathematical artifact or "formula" created by the machine learning algorithm after it finishes studying the training data.
  • Real-World Example: A recipe created by a chef after experimenting with 1,000 ingredient combinations.
  • Technical Explanation: A parameterized function $f(\mathbf{x}; \mathbf{w})$ where $\mathbf{w}$ are learned internal weights/coefficients. Before training, $\mathbf{w}$ are random or zero. After training, $\mathbf{w}$ represent fine-tuned values that accurately map inputs to predictions.

13. What Does "Training a Model" Actually Mean?

  • Simple Definition: Training is the automated trial-and-error process where the computer adjusts its internal mathematical knobs (weights) to make its predictions as close as possible to the real answers.
  • Real-World Example: An archer adjusting their bow angle after every shot until they consistently hit the bullseye.
  • Technical Explanation: An optimization loop (e.g., L-BFGS, Stochastic Gradient Descent) that calculates the gradient of the loss function with respect to weights $ rac{\partial \mathcal{L}}{\partial \mathbf{w}}$ and iteratively updates weights until the loss reaches a minimum.

4. N-Grams: Unigrams, Bigrams, and Trigrams

  • Unigram (1-gram): A single isolated word: ["the", "movie", "was", "not", "good"].
  • Bigram (2-gram): A sequence of two consecutive words: ["the movie", "movie was", "was not", "not good"].

Why Bigrams are Essential in Our Project: Under unigrams alone, the sentence "not good" is split into two separate words: "not" and "good". In our trained Logistic Regression model, "not good" received a massive negative coefficient of -2.646, completely resolving the negation!

PART 6 — TF-IDF VECTORIZATION & DATA LEAKAGE

1. The Limitations of Simple Bag-of-Words (CountVectorizer)

The simplest way to convert text to numbers is Bag of Words: count how many times each word appears in a document. For example, if "great" appears 3 times, its feature value is 3.

The Fatal Flaw: In any movie review corpus, words like "movie", "film", "watch", and "scene" appear in virtually every single review. In Bag-of-Words, these generic words receive the highest counts, dominating the feature space even though they contain zero discriminative sentiment information!

2. The Core Intuition of TF-IDF

TF-IDF fixes Bag-of-Words with a simple, brilliant intuition:

  1. If a word appears frequently in a specific review, it must be important to that review (↑ High Term Frequency).
  2. However, if that same word appears in almost every review across the entire dataset, it is useless for distinguishing positive from negative (↓ Low Inverse Document Frequency penalty).
  3. Therefore, words that are frequent in one review but rare across the whole corpus (like "masterpiece" or "abysmal") receive the highest TF-IDF score!

3. The Mathematical Formula (Scikit-Learn Implementation)

$$ ext{TF-IDF}(t, d, D) = ext{TF}(t, d) imes ext{IDF}(t, D)$$

Term Frequency (TF):

In our project, we enabled sublinear_tf=True. Instead of raw counts, term frequency is scaled logarithmically:

$$ ext{TF}(t, d) = 1 + \log( ext{count}(t, d)) \quad ext{for count} > 0$$

Why? A word appearing 20 times in a long review is not 20 times more important than a word appearing once. Log scaling dampens the dominance of repeated words.

Inverse Document Frequency (IDF) with Smooth IDF:

$$ ext{IDF}(t) = \log\left( rac{1 + N}{1 + ext{DF}(t)} ight) + 1$$

  • $N$: Total number of documents in the training corpus ($N = 39,665$).
  • $ ext{DF}(t)$: Document Frequency — the number of documents containing term $t$.
  • The constant $+1$ in the numerator and denominator prevents division by zero.
  • The $+1$ outside the logarithm prevents terms with $ ext{DF}(t) = N$ from receiving zero weight entirely.

4. Step-by-Step Numerical Example

Suppose our corpus has $N = 10,000$ reviews. Consider two terms in a review:

Word Count in this review DF (Total reviews containing word) Calculated IDF Final TF-IDF Score Interpretation

5. Critical Parameters of TfidfVectorizer in Our Project

vectorizer = TfidfVectorizer(
    ngram_range=(1, 2),
    max_features=10000,
    min_df=3,
    sublinear_tf=True
)
  • ngram_range=(1, 2): Extracts both single words and consecutive 2-word combinations to capture phrases like "not good".
  • max_features=10000: Selects the top 10,000 terms ordered by term frequency across the corpus. Discards the long tail of 200,000+ noisy terms, preventing overfitting and reducing RAM usage.
  • min_df=3: Discards terms appearing in fewer than 3 documents. Purges rare typos (e.g. "goooood") and random noise.
  • sublinear_tf=True: Applies logarithmic scaling $1 + \log( ext{tf})$ to term frequency.

6. What is Data Leakage and How Did We Prevent It?

Data Leakage is a fatal machine learning flaw where information from the testing/evaluation dataset leaks into the training process before model fitting. This causes models to look amazing during development but completely fail in production.

THE CARDINAL RULE OF VECTORIZATION:

fit_transform(X_train) on Training Data • transform(X_test) on Testing Data

  • fit() calculates the vocabulary list and the global IDF weights ($ ext{DF}(t)$ for all words).
  • If you call fit(X) on the full dataset, your model learns IDF scores and vocabulary frequencies calculated from the unseen test set — a direct data leak!
  • In our project: 
    # Correct Implementation in src/train_model.py:
X_train_tfidf = vectorizer.fit_transform(X_train) # Learns vocab & IDF weights ONLY on train
X_test_tfidf = vectorizer.transform(X_test)       # Reuses train weights to transform test

2. To prevent "didn't" from becoming "didnt" or losing the negation "not" when punctuation is stripped.

PART 7 — MACHINE LEARNING CLASSIFIERS: LOGISTIC REGRESSION & NAIVE BAYES

1. The Classification Task in Feature Space

Once TF-IDF transforms each review into a 10,000-dimensional numerical vector $\mathbf{x} = [x_1, x_2, \dots, x_{10000}]^T$, our machine learning task is to learn a mathematical decision boundary that separates positive vectors from negative vectors.

2. Model 1: Logistic Regression (Winning Model — 90.23% Accuracy)

Despite its name containing "Regression", Logistic Regression is a linear classification algorithm that predicts the probability of a categorical outcome.

Mathematical Formulation:

  1. Linear Score Calculation: The model computes a weighted sum of all input features plus an intercept (bias) term: $$z = w_0 + w_1 x_1 + w_2 x_2 + \dots + w_d x_d = \mathbf{w}^T \mathbf{x} + b$$ Here, each $w_j$ represents the learned coefficient for word $j$. A positive weight (e.g. $+2.4$ for "masterpiece") pushes the score toward Positive; a negative weight (e.g. $-2.6$ for "not good") pulls it toward Negative.
  2. Sigmoid (Logistic) Function: The continuous linear score $z \in (-\infty, +\infty)$ is mapped into a valid probability $P \in (0, 1)$ using the standard Sigmoid curve: $$\sigma(z) = rac{1}{1 + e^{-z}} = P(y=1|\mathbf{x})$$
    • If $z = 0 \implies \sigma(0) = rac{1}{1 + 1} = 0.50$ (Exact boundary).
    • If $z = +3 \implies \sigma(3) pprox 0.95$ (95% confident Positive).
    • If $z = -3 \implies \sigma(-3) pprox 0.05$ (5% positive $\implies$ 95% confident Negative).
  3. Decision Threshold: By default, if $P(y=1|\mathbf{x}) \ge 0.50$, the review is classified as Positive (1); otherwise, Negative (0).
  4. Binary Cross-Entropy Loss (Log-Loss): The objective function minimized during training: $$\mathcal{L}(\mathbf{w}) = - rac{1}{N} \sum_{i=1}^N \left[ y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) ight] + rac{1}{2C} \|\mathbf{w}\|_2^2$$ The term $ rac{1}{2C} \|\mathbf{w}\|_2^2$ is L2 Regularization (Ridge penalty), which shrinks large weights to prevent overfitting on specific words. The parameter $C=1.0$ controls the trade-off between fitting training data and keeping weights small.

3. Model 2: Multinomial Naive Bayes (Baseline — 86.95% Accuracy)

A probabilistic classifier based on Bayes' Theorem tailored for discrete word counts and frequencies.

Bayes' Theorem:

$$P( ext{Class}|X) = rac{P( ext{Class}) imes P(X| ext{Class})}{P(X)}$$

  • $P( ext{Class})$ is the Prior Probability (50% for positive, 50% for negative in our balanced dataset).
  • $P(X| ext{Class})$ is the Likelihood of observing these specific words given the sentiment class.

The "Naive" Assumption:

Naive Bayes assumes that all words in the document are conditionally independent of one another given the class label:

$$P(w_1, w_2, \dots, w_n| ext{Class}) = \prod_{i=1}^n P(w_i| ext{Class})$$

Laplace (Additive) Smoothing ($lpha = 1.0$):

$$\hat{P}(w_i| ext{Class}) = rac{ ext{Count}(w_i, ext{Class}) + lpha}{\sum_{w} ext{Count}(w, ext{Class}) + lpha \cdot |V|}$$

Why is it mandatory? Without Laplace smoothing ($lpha=0$), if a test review contains a single word never seen in positive training reviews, $P(w| ext{Positive}) = 0$. Because all probabilities are multiplied together, the entire calculation collapses to zero ($0 imes \dots = 0$)! Adding $lpha=1$ ensures every word has a tiny non-zero probability.

2. Evaluation Formulas & Numerical Walkthrough

  • Accuracy: The proportion of all predictions that were correct: $$ ext{Accuracy} = rac{TP + TN}{TP + TN + FP + FN}$$
  • Precision: When the model predicts Positive, how often is it right? $$ ext{Precision} = rac{TP}{TP + FP}$$
  • Recall (Sensitivity): Out of all actual Positive samples, how many did the model catch? $$ ext{Recall} = rac{TP}{TP + FN}$$
  • F1-Score: The harmonic mean of Precision and Recall: $$ ext{F1-Score} = 2 imes rac{ ext{Precision} imes ext{Recall}}{ ext{Precision} + ext{Recall}} = rac{2TP}{2TP + FP + FN}$$

PART 15 — MODEL SERIALIZATION & JOBLIB

1. Why Model Serialization is Essential

Training an NLP model on 50,000 documents requires parsing text, computing vocabulary frequencies across 40,000 reviews, and running iterative mathematical optimization. This takes ~30 seconds. In production, an API or web service cannot pause for 30 seconds every time a customer submits a review. Serialization freezes the trained mathematical state (learned weights $w_j$ and vocabulary mappings) and saves them as a binary byte stream on disk.

2. Why joblib Over Standard pickle?

Python's built-in pickle module serializes generic Python objects. However, joblib is specifically engineered for scientific computing. It handles large NumPy arrays and Scikit-Learn sparse matrices with continuous memory mapping and compression, executing load and save operations significantly faster with lower memory consumption.

3. Why the Vectorizer MUST be Serialized Alongside the Model

Critical Interview Trap: If an interviewer asks: "Can I just save my trained Logistic Regression model and use a new TfidfVectorizer during deployment?"
Answer: "Absolutely NOT! The Logistic Regression model learned that weight $w_{412}$ belongs to 'masterpiece' and weight $w_{8901}$ belongs to 'not good'. A new vectorizer would assign completely different index numbers to words based on new inputs. The exact same fitted vectorizer dictionary must be saved and loaded alongside the model to guarantee identical feature indices!"

1. The Four Inherent Limitations of Classical N-gram Models

Q11. Derive and explain the TF-IDF formula used in Scikit-Learn.

  • Short Answer: $ ext{TF-IDF} = ext{TF} imes ext{IDF}$. TF measures term frequency in a document; IDF measures the rarity of the term across all documents ($\log( rac{1+N}{1+DF}) + 1$).
  • Detailed Answer: Scikit-Learn uses the Smooth IDF formulation: $ ext{IDF}(t) = \log\left( rac{1 + N}{1 + ext{DF}(t)} ight) + 1$, followed by L2 Euclidean normalization on each row vector $\mathbf{v}_{ ext{norm}} = rac{\mathbf{v}}{\|\mathbf{v}\|_2}$. This ensures document length does not bias cosine distances between vectors.
  • Why They Ask: Mathematical precision and Scikit-Learn framework depth.
  • Common Mistake: Stating the raw textbook formula $\log(N/DF)$ without the $+1$ smoothing constants.

Q12. What does sublinear_tf=True do and why did you use it?

  • Short Answer: It replaces raw term frequency $ ext{TF}$ with $1 + \log( ext{TF})$. It prevents a word appearing 20 times from having 20 times more influence than a word appearing once.
  • Detailed Answer: Human perception of frequency is logarithmic (Weber-Fechner Law). In movie reviews, an author repeating the word "boring" 10 times is not 10 times more dissatisfied than an author writing it twice. Log scaling dampens repetition bias.
  • Why They Ask: Tests advanced hyperparameter tuning knowledge.
  • Common Mistake: Confusing sublinear TF with sublinear IDF.

Q13. Why is Logistic Regression considered a linear model if the Sigmoid curve is non-linear?

  • Short Answer: Because the decision boundary in the feature space is a linear hyperplane ($z = \mathbf{w}^T \mathbf{x} + b = 0$).
  • Detailed Answer: The log-odds (logit) function is a strictly linear combination of input features: $\log\left( rac{P}{1 - P} ight) = \mathbf{w}^T \mathbf{x} + b$. The non-linear Sigmoid function $\sigma(z)$ only acts as a monotonic squashing function to map the linear score into probability space $[0, 1]$. The boundary between classes is a flat hyperplane.

  • Detailed Answer: Unlike Ordinary Least Squares (OLS) regression, Logistic Regression has no closed-form analytical solution. It uses numerical optimization.
